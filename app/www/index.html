外观

选择会即时生效并保存在浏览器本地。

网络代理

代理将注入 QwenPaw 服务的出站环境变量（HTTP_PROXY / HTTPS_PROXY / ALL_PROXY），用于访问 GitHub 等外部服务；保存后需重启 QwenPaw 生效。配置代理可让「检查更新」在受限网络下正常工作。

重置访问密码

已设置访问密码，需输入当前密码确认身份（防止外网控制台被恶意改密）

重置后旧会话将全部失效，需使用新密码重新访问网关。请在受信任的网络环境中操作。
